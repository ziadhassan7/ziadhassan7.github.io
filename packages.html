Upstream contribution

ngenius_flutter_sdk

Flutter plugin for N-Genius card payments on Android and iOS

The plugin wraps the native N-Genius payment SDKs so a Flutter app can take card payments. I worked with N-Genius payments at YAY Global, and for this plugin I built saved-card payments on both platforms and contributed the work upstream. The feature ships in the published package, and the README credits me as a contributor.

What I contributed

  • Saved-card payments from end to end: implemented the launchSavedCardPayment call on the native side, in Kotlin for Android and Swift for iOS.
  • Support for older Flutter versions, so existing apps can adopt the plugin without upgrading first.
  • Android build fixes, including JitPack repository placement and missing SDK dependencies.
  • Better package documentation.

Responsive layout

A container that behaves normally on small screens and wraps its content in a box on large screens and the web.
